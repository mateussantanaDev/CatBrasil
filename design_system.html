Caterpillar UI

Documentação de Design System: Brutalismo Funcional e Confiança Inabalável

1. Posicionamento de Marca

A interface da Caterpillar não é apenas um site, é um painel de controle industrial. A estética deve evocar força, durabilidade e trabalho pesado. Não há espaço para animações supérfluas ou elementos frágeis. A prioridade é a eficiência, o alto contraste e a legibilidade sob qualquer condição (como a tela de um tablet sob o sol em um canteiro de obras).

Princípio O Que Fazer (How) Onde Usar (Where) Quando Usar (When)
Funcionalidade Pura Mantenha layouts estruturados em blocos (grids óbvios). Evite espaços vazios excessivos que não tenham função. Páginas de catálogos de máquinas, tabelas de especificações e dashboards. Sempre. O design deve ser visto como uma ferramenta utilitária.
Tato Industrial Use bordas sólidas, sombras "duras" (sem blur) e cantos levemente arredondados (2px). Botões, cards de produtos, modais de erro ou sucesso. Quando o usuário precisar interagir com o sistema (clicar, arrastar, selecionar).

Cor Como Usar (How) Onde Usar (Where) Quando Usar (When)
Cat Yellow Sempre com texto em Preto (#111111) para garantir acessibilidade e contraste visual. Nunca use como fundo para textos longos. Botões primários (CTAs), ícones de destaque, sublinhados de títulos, alertas de atenção. Para chamar a atenção imediata para a ação principal da tela (ex: "Solicitar Orçamento").
Industrial Black Como cor de fundo principal ou para tipografia pesada. Pode cobrir grandes áreas do layout. Cabeçalhos (Headers), rodapés (Footers), seções de "Hero" (topo da página), texto principal. Para ancorar o layout e dar peso à interface, contrastando com o amarelo.
Steel Gray Para criar hierarquia e separação sem o peso total do preto. Bordas de tabelas, backgrounds de seções secundárias, botões desabilitados. Para separar informações técnicas complexas, como peças de reposição e especificações de motor.

3. Tipografia

A tipografia reforça a engenharia mecânica: é estrutural, condensada nos títulos e altamente legível nos dados técnicos.

Display / Headings (Oswald)

Potência Inabalável

Peso: Bold (700) ou Black (900) | Transformação: Sempre UPPERCASE.

Body / Interface (Inter)

Equipadas com motores eficientes, estas escavadeiras oferecem o máximo de produtividade com o menor custo de combustível. Confiabilidade é a nossa marca registrada.

Peso: Regular (400) ou Medium (500) | Uso normal de caixa alta e baixa.

Dados Técnicos (JetBrains Mono)

Potência Líquida: 320 HP | Torque: 1200 Nm | RPM: 1800

Peso: Medium (500) | Alinhamento tabular para facilitar a leitura de métricas.

Fonte Como Usar (How) Onde Usar (Where) Quando Usar (When)
Oswald Apenas em caixas altas (Uppercase). Mantenha o espaçamento de letras (letter-spacing) levemente ajustado para legibilidade (+1px). Títulos de páginas (H1, H2), banners promocionais, nomes das séries de máquinas (ex: CAT 320). Na introdução de novos blocos de conteúdo para criar impacto visual forte.
Inter Tamanho base de 16px. Mantenha uma altura de linha (line-height) de 1.5 a 1.6 para leitura confortável. Descrições de produtos, textos de apoio, formulários, menus de navegação. Para qualquer texto que o usuário precise ler em detalhe.
JetBrains Mono Use tamanhos menores (14px). Ótima para alinhar números verticalmente. Fichas técnicas, dimensões de implementos, painéis de telemetria, tabelas de torque/potência. Sempre que dados numéricos ou atributos mecânicos exatos forem o foco da informação.

4. Componentes UI

Botões (Ações)

Componente Como Usar (How) Onde Usar (Where) Quando Usar (When)
Primary Button Brutalista: borda preta sólida, sombra dura preta deslocada (+4px, +4px). O clique (estado :active) deve "afundar" o botão removendo a sombra. Finalizar compras, enviar formulários de contato, baixar manuais importantes. Apenas uma vez por tela ou bloco para não diluir o foco da ação principal.
Secondary Button Sem cor de fundo (transparente), mantendo a borda sólida e sombra dura (cinza ou preta) para manter o peso estrutural. Links secundários, "Saiba mais", filtros de busca. Para ações de suporte ou fluxos paralelos que não devem ofuscar o CTA principal.
Cards de Produto Fundo branco, borda de 2px preta. Deve parecer uma "ficha de identificação" industrial impressa. Catálogos de escavadeiras, listagem de peças. Para agrupar uma foto da máquina com seus dados técnicos principais (Nome, HP, Peso).

5. Implementação & Integração

Este sistema pode ser facilmente mapeado para o ecossistema de desenvolvimento moderno, como um ambiente SvelteKit usando Tailwind CSS. A configuração abaixo padroniza a linguagem visual no código.

Tailwind CSS Configuration (tailwind.config.js)

export default {
  content: ['./src/**/*.{html,js,svelte,ts}'],
  theme: {
    extend: {
      colors: {
        cat: {
          yellow: '#FFB200',
          black: '#111111',
          gray: '#2D2D2D',
          white: '#F4F6F8',
          red: '#D32F2F'
        }
      },
      fontFamily: {
        display: ['Oswald', 'sans-serif'],
        body: ['Inter', 'sans-serif'],
        mono: ['JetBrains Mono', 'monospace'],
      },
      borderRadius: {
        industrial: '2px',
      },
      boxShadow: {
        hard: '4px 4px 0px 0px rgba(17,17,17,1)',
      }
    },
  },
  plugins: [],
}

Como estruturar no Frontend: Recomenda-se abstrair os elementos de UI (como botões e cards) em componentes isolados (ex: Button.svelte), aplicando essas classes utilitárias internamente. Assim, o design se mantém consistente por toda a aplicação sem repetição excessiva de classes do Tailwind em cada página.
